# Roadmap

Deferred until actual usage supports prioritization: more categories; controlled functional capability tests; compatibility change alerts; saved tool collections; private approved catalogs; paid monitoring/team features.

Not in this release: billing, enterprise workspaces, private catalogs, user accounts, ratings/reviews, comparison dashboards, public submission queues, automatic installation, third-party credential custody, arbitrary third-party execution, AI chat, WebMCP or a general crawler.

Engineering follow-ups: more independently reviewed search queries, multilingual retrieval, richer version-pinned tool curation, stricter nonce-based CSP, immutable container digests, large-catalog SQL filtering/counting, hosted client installation tests and an off-host recovery drill. None imply customer demand or an implementation commitment.
